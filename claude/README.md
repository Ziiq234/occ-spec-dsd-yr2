# claude/ — Claude's space

This folder is for Claude to keep its own working notes and skills between sessions, so it doesn't have to rediscover things.

- `notes/working-notes.md` — decisions, facts confirmed by Jamie, open questions. Read at the start of a session; append when something changes.
- `notes/session-log.md` — one short line per working session.
- `skills/occ-spec-coach/SKILL.md` — how to coach Jamie on this qualification. To use it as a real Claude skill, copy the folder into `~/.claude/skills/` (Claude Code) or upload it as a skill in Claude settings.

# learning/ — everything for learning up to Task 1 (9 March 2027)

**Aim:** Distinction. **When:** Tue, Wed and Fri evenings, ~1 hr 30. **Live schedule:** [Learning Plan sheet](https://claude.ai/artifact/GfsJi25JqVVjFyuV1D1fLg).

| File / folder | What it's for |
|---|---|
| [`learning-plan.md`](learning-plan.md) | The plan: every unit (0–32), what it covers and what "done" looks like |
| [`daily-schedule.csv`](daily-schedule.csv) | Backup of the sheet's Daily schedule — 40 sessions with dates and timed plans |
| [`spec-coverage.md`](spec-coverage.md) | Every spec content area (1.1–8.4) → which units teach it → where it's marked |
| [`progress.md`](progress.md) | Tracker: status and confidence per unit, plus a session log |
| [`sessions/`](sessions) | One short note per session — what was covered, mark given, weak spots, next step |
| [`practice/`](practice) | The work produced in sessions, one folder per unit (mostly the Netheret brief) |

## How a session runs
1. Start with `/occ-spec-tutor` (or "let's do tonight's Occ Spec session").
2. Recall quiz on last time → learn → worked example on a different brief → do it for Netheret → mark against the mark scheme → fix the weakest part.
3. Claude saves the work in `practice/`, a note in `sessions/`, updates `progress.md` and the sheet, then commits and pushes.

# Specification summary — Gen 2 Digital Software Development

Source: [Pearson T Level TQ in Digital Software Development specification v1.0, May 2025](https://qualifications.pearson.com/content/dam/pdf/TLevels/digital-software-development/2025/specification-and-sample-assessment-materials/digital-dsd-specification.pdf)

## Facts

- Occ Spec = 630 GLH / 900 TQT, **50%** of the Technical Qualification.
- One externally set synoptic project: **144 marks**, ~**50.5 supervised hours**, March–May window, set and marked by Pearson, submitted as an electronic portfolio.
- Parts: Task 1 (analysis and design), Task 2 (development), Task 3a (gathering feedback), Task 3b (evaluation).
- Graded **Pass / Merit / Distinction / Unclassified**.
- T Level needs at least an E in the Core and a Pass in the Occ Spec (plus industry placement). Distinction* overall = A* Core + Distinction Occ Spec.
- **Permitted languages (pick at least two):** Python 3 (3.10+), C#, SQL, JavaScript, PHP.
- **Internet:** allowed in every task except 3b.

## AI rules (from the task booklets)

| Task | AI allowed? |
|---|---|
| Task 1 | Only in Activity C — **required** there, for code snippets (max 5 problems), with prompts and reviews logged |
| Task 2 | Only to generate small sections of code and to test/debug. Not to produce the whole solution |
| Task 3 | No AI. 3b also has no internet |

## Content areas to know

1. **Analyse a problem** — SDLC stages; scoping; functional and non-functional requirements; KPIs; acceptance criteria; scheduling; costing; choosing a language; risks; user stories, ERDs, activity diagrams; using generative AI for code with review. Team roles (product owner, scrum master, tech lead, PM, systems analyst, UX/UI, developer, ops, security, testers). Methodologies: Agile, Scaled Agile, Waterfall, RAD, Lean, User Centred Design. Secure by design; spike testing. Emerging tech: AI, IoT, biometrics, robotics, cloud, data lakes, drones, 3D printing, networks.
2. **Ethics, law and risk** — IP, consumer protection, age ratings, advertising, data protection, copyright and patents, gambling, employment, territorial restrictions, system security, equality. Standards: **ISO/IEC/IEEE 90003:2018**, **W3C**. Codes of conduct, licensing, inclusion. Risk: likelihood vs seriousness, mitigation, contingency, monitoring, backups, **CIA**, business continuity, disaster recovery.
3. **Reliable sources** — search engines, wikis, blogs, papers, peers, forums, code comments, repositories. Judge by author reputation, bias, evidence, cross-referencing, currency.
4. **Design** — top-down, OOP, data models, TDD, BDD; gitFlow / GitHub Flow; UX/UI (wireframes, style guides, clickable prototypes); CMS; flowcharts and pseudocode; asset selection; target platforms; **data dictionary, ERD, 3NF**; network integration points.
5. **Collaboration** — why collaborate; version control, source control, IDE tools; code reviews.
6. **Implementation** — 2+ languages front end and back end; tools and APIs; packaging; CI/CD stages; coding conventions; 12-factor principles; UI techniques; API/JDBC/ODBC; deployment.
7. **Testing** — unit, smoke, integration, system; availability, compatibility, configuration, load; front-end; security; acceptance, alpha, beta, closed-box, open-box; valid / invalid / extreme / erroneous data. AI tools allowed in testing.
8. **Change, maintain, support** — drivers of change; change management (planning, scheduling, regression testing, controlled release); maintainable code; user support.

## Gen 1 vs Gen 2

| | Gen 1 — Digital Production, Design and Development | Gen 2 — Digital Software Development |
|---|---|---|
| Cohorts | 2020–2024 | 2025–2029 |
| Time | 67 hrs | 50.5 hrs |
| Marks | 145 | 144 |
| Languages | Provider chooses | Fixed list of 5 |
| AI | Not part of the assessment | Required in 1C, limited in Task 2 |
| PO5 sources / PO6 ethics | 13 / 10 marks | 18 / 18 marks |

# Submission file names

Replace `[RegNo]` with your registration number, `[Surname]` with your surname and `[I]` with the first letter of your first name. Multiple files → add `_01`, `_02` …

| Task | What | File name | Format |
|---|---|---|---|
| 1 | Proposal (with research appendix) | `Task1_Proposal_[RegNo]_[Surname]_[I]` | PDF |
| 1 | Each design document | `Task1_DesignDocs_[DocName]_[RegNo]_[Surname]_[I]` | PDF |
| 1 | AI log | `Task1_AILog_[RegNo]_[Surname]_[I]` | PDF |
| 2 | Prototype — build, source code, screencast | Any sensible folder structure | Any |
| 2 | Change and source log | `Task2_ChangeSource_log_[RegNo]_[Surname]_[I]` | PDF |
| 2 | Test log | `Task2_TestLog_[RegNo]_[Surname]_[I]` | PDF |
| 3 | Feedback materials and records | `Task3_Feedback_[DocName]_[RegNo]_[Surname]_[I]` | Any suitable |
| 3 | Evaluation report | `Task3_Evaluation_[RegNo]_[Surname]_[I]` | PDF |

## Layout and spacing
- Grid: e.g. 12 columns desktop, 4 mobile
- Spacing scale: 4 / 8 / 16 / 24 / 32 px
- Breakpoints: mobile < 768px, tablet 768–1024px, desktop > 1024px
- Navigation: top bar on desktop, hamburger on mobile

## Components
Buttons (primary/secondary/disabled), form fields (label above, error below in red with icon), cards, tables, alerts, modals, icons (standard set, e.g. house = home).

## Accessibility
- WCAG 2.2 AA
- Alt text on all images
- Focus outlines visible
- Not colour alone for meaning
- Keyboard navigable
